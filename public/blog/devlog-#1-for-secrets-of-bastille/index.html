Devlog #1 for Secrets of Bastille

Mar 18, 2026

Been making some progress on Demo 2! Was going to re-do the dungeon system for the MZ version but I decided to make it work in Demo 2 and have a page open for it on RPG Maker Web.

I am working with ChatGPT to help create some plugins while I do the code review with the UI. I am aiming for a Dragon Quest/Mystery Dungeon style UI as you can see in the screenshot below

Some of the things I have added so far is a new dungeon format, UI changes, changing the Font, and working on the databases. There’s a lot of events I would need to work on before I start stat balancing but I am enjoying the game so far.

This brings me back to the good ol days of staying up late with best friends messing around with RPG Maker 2000. This game is for the homies. Been pretty busy so far so I’m hoping to work on this as much as I can.

I’m expecting Demo #2 to come out before May and hoping to release it in April!

Let’s do this.
