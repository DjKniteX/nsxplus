Welcome to NSXplus!

Mar 5, 2026

Hello everyone! Welcome to NSXplus! Named with my initials and my (future) love of the MSX computers. I am rebranding to do a lot of retro coding which I hope to dev log and open up a youtube channel as well, something along the lines of LGR and 8bitguy but more towards coding 8bit games.

It’s still in early stages but I would try to blog all things retro tech as well as my cybersecurity journey. Which on the other hand, have gotten to an okay start where I volunteered to do some website testing where I attempted to do an SQL injection and ran Burp Suite to find cookie vulnerabilities. So far so good on that end.

My Mirage Wars game is almost done. I have just finished up the Prologue version and will post a github link since I would like to make most of my stuff open source and free. I am working on an extended/full release version that will include more features than the prologue such as a more intensive combat system and improved gameplay.

Named after my favorite coding community

Mirage Wars is dope wars clone that is part of a set of text-based games for the C64 which I hope to end the series with a full-fledged game made in Assembly.

You play as Simon, a Source Runner looking to sell stolen source codes throughout the community to make sure organizations such as the X’lithan Organization take it for their own personal gain. You buy and sell bits of a source code so no one has the full source making it harder for the corrupted corporations to take and use.

Anyways, that’s it for now. Looking to start a youtube channel soon and will continue to use my twitch.tv/djknitex for live streams (if I get that far to live stream or just do it on youtube)
