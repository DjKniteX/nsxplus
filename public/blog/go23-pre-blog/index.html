GO23 - Pre Blog

Nov 2, 2023

Hey guys, taking a 95% pause on HG right now to focus on Game Off 2023! I didn’t get to do it last year since we did the multiplayer summer jam one but this time we are going in full force!

This year we will be learning Godot and turning this project into a text- adventure game that takes place in Space with the theme of Scales.

The game will obviously be open source and so the game will be titled: The Tales of Three Scales.

A short text-adventure game where you are finding scales… for a reason!

Anyways, this is just a pre-log so stay tuned for more blogs soon!
