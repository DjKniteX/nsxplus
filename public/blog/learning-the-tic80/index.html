Learning the Tic80

Mar 12, 2026

I’m back with another update and this time I’m leaning into the Tic-80 Fantasy Console.

I really like how you can use multiple languages but I ended up going to stick with Lua incase I want to work on projects in Pico-8 or try Love2D again.

I also like how it’s open-source and essentially free with a pro version so I can experiment with no issues. Other features I like is more resolution and able to use keyboard/mouse (point and click adventure games anyone?), as well as addtional players and controller buttons.

When I typed it into ChatGPT they mentioned that it’s closer to the early Amigas in terms of processing power and graphics.

So I’m going to mess around with it and see if I can push something up to be playable. I would need the pro version (thankfully I can compile it on my own)

Fridays are usually my project days where I just do stuff at work. Monday - Thursday I am watching Comp Sci courses and learning Assembly, Basic, and C++.

My next venture would be Basic8, especially since I like coding in Basic and want something modern retro if that make sense.

I also pushed a new chapter for my webnovel, Actions Per Minute which you can read here: Actions Per Minute

Stay tuned for new stuff! Eldiron 0.9 has been dropped and I’ll definitely be using that for a project.
